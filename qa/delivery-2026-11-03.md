## Cause and change

The largest source, Studio, is dominated by existing Meshopt v0 attribute streams rather than image payload. Increasing the old codec's compression level reproduced the same bytes. The pinned Three.js 0.186.1 loader and its bundled decoder also support the KHR extension and v1 codec. The build now re-encodes existing attribute streams with that codec without reordering, welding, quantizing, resampling, or applying any new filter. Existing filter storage is decoded without the filter, compressed again, then checked byte-for-byte both before and after its original filter. Index streams remain verbatim. The glTF extension/fallback tags are correctly upgraded to KHR; source files remain untouched.

Khronos explicitly describes lossless EXT→KHR conversion and recommends v1 for loaders supporting both: [KHR_meshopt_compression content guidelines](https://github.com/KhronosGroup/glTF/tree/main/extensions/2.0/Khronos/KHR_meshopt_compression#content-guidelines). This is a delivery-only change, with no reduction in GPU geometry, texture quality, silhouettes, animation precision or draw calls. The previously transitive Meshopt encoder is now declared as a pinned build dependency (`meshoptimizer@1.1.1`) for clean-build reproducibility.

The runtime's local asset URLs now carry the generated decoded-payload SHA-256 as `?v=...`. The delivery proxy grants immutable caching only when that revision matches the current entry. Unversioned/unknown/stale paths continue to revalidate. Content-addressed delivery files are also immutable; the mutable manifest remains no-store. Integrated HTTP tests caught the rewritten hashed destination overriding the mutable source cache policy. Next can issue a second HTTP request for a rewrite whose local origin differs after hostname normalization. Cache policy now lives in the proxy, and a revalidation marker travels with mutable rewritten requests so either rewrite path preserves it. No untrusted Host header is used to construct a destination. External CDN releases retain their existing URL/configuration contract. Encoding negotiation and Vary stay unchanged.

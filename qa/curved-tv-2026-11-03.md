## Root causes and repairs

- A flat DOM plane could not coincide with the curved LED: its center is about 714 mm behind the edge chord. Sixteen adjacent DOM fragments now follow UV-derived world patches from the original mesh, using homogeneous projection for close, partial and pitched views. Maximum chord deviation is 2.788 mm; the actual mesh/depth surface is unchanged.
- MutationObserver cannot see Motion's compositor-owned keyframes. The animation bridge now mirrors actual WAAPI effects and synchronizes CSS effects across document timelines. This fixes stale transforms/opacity and the black or wood-filled vertical blocks during card selection.
- Forced root visibility overrode hidden patch hosts. Roots now inherit visibility, so offscreen/back-facing sections cannot paint through their hidden hosts.
- An extra opaque host background bled through antialiased fragment boundaries. The source stage already supplies the opaque wood backdrop; removing the duplicate background cleaned the dark joins.
- `visibility:hidden` culling retained off-strip animated/filter surfaces across all 16 fragments. Fully culled cards now use `display:none`; CSS animations recreated on reveal are resynchronized to the real app's current phase. Only visible effects render. Source layout stays available in the real iframe.
- Camera-dependent guard widths forced layout during camera motion. Fixed source-space guards retain stable raster dimensions and exact source UV registration. Hover propagation updates only changed state; unchanged paused animation clocks are not repeatedly written.
- Incremental builds can leave temporary gaps in the source-to-copy arrays. Hover/form propagation now skips not-yet-built copies; reconciliation fills them without errors.

One native same-origin iframe owns application state, focus, controls, forms and navigation. The fragments are inert visual copies, not sixteen apps. Native pointer coordinates map through actual mesh UVs; furniture and the visitor retain normal depth occlusion. Expansion/return keep the same iframe and selected film. The returning view is prepared before fullscreen uncovers the lounge.

TV-only layout hides the wordmark, raises title/metadata and enlarges the active card from about 206×265 to 280×360 px. Footer targets are at least 44 px high. Standalone/expanded Studio keeps its wordmark and layout. Wood-only background, gold frames, original image detail, light shafts, glass effects, render scale and 4096-square shadows are preserved.
